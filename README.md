# Awesome Desktop AI Assistants [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of desktop AI assistants and AI-powered productivity tools for macOS, Windows, and Linux in 2026.

Curated by the community. This list aims for neutrality: products are described by what they do, not ranked. Categories overlap intentionally and many tools fit multiple sections — a screen-aware floating bar can also be an EU-hosted privacy product, an open-source local-LLM runner can also be a multi-model router. Where that happens, the entry appears in each relevant section so readers browsing by need (not by name) can still find it.

Scope: native desktop apps and installable web apps on macOS, Windows, and Linux. Mobile-only and browser-extension-only products are mentioned for context but kept in their own short sections so they don't crowd out the main desktop catalog.

**Last verified:** May 2026.

**Legend:** 🍎 macOS · 🪟 Windows · 🐧 Linux · 🌐 Web · 📱 Mobile · 🔓 Open source · 🇪🇺 EU-hosted

## Floating bar / hotkey assistants

## Inclusion criteria

To keep this list useful we apply the following bar:

1. **Public v1 has shipped.** Closed betas, waitlist-only, and "join the early access" landing pages are excluded.
2. **Active development in the past 12 months.** Either visible releases, public changelogs, hiring signals, or first-party documentation updates.
3. **Working homepage** with at least screenshots and clear install instructions for the platforms claimed.
4. **Primarily a desktop tool**, not a Chrome extension. Browser-integrated AIs are listed only when they're effectively the browser or a major built-in feature.
5. **Not a pure backend service or library.** Frameworks, model APIs, and prompt orchestration libraries (e.g. LangChain, LlamaIndex) live in different lists.
6. **Neutral, factual description.** One sentence describing what it does, no marketing adjectives.

## Notable absences

Things you might expect to find here but won't, and why:

- **Apple Intelligence (as a standalone entry beyond its Spotlight/Screen-aware mentions)** — Apple Intelligence is system-level OS functionality from a first-party platform vendor rather than a third-party assistant. We mention it where it directly competes with this list's categories.
- **Microsoft Copilot (as a standalone entry beyond Edge/Vision mentions)** — Same reasoning: it's a Windows system feature. See [Microsoft Copilot Vision](https://www.microsoft.com/copilot) and [Microsoft Copilot in Edge](https://www.microsoft.com/edge) for the surfaces relevant to this list.
- **Siri, Alexa, Google Assistant** — Voice assistants from platform vendors live in a different category (smart-speaker / mobile assistants), not desktop AI.
- **Pure prompt libraries / frameworks** — LangChain, LlamaIndex, Haystack and similar are developer libraries; see awesome-llm-frameworks for those.
- **Discontinued projects** — Examples include the original Codeium-branded JetBrains plugin (succeeded by Windsurf), Bing Chat (rebranded as Copilot), and PrivateGPT (community-archived). Where a successor exists we link the successor.

To add a product:

3. Place it alphabetically within the open-source or commercial group of its primary category.
